### 🔹 Data Structures & Algorithms (DSA)

#### 📌 Reverse a Linked List

### 💡 Concepts Used:
- Pointer manipulation
- Iterative approach
- Understanding node connections
- Handling head changes carefully

### 🧠 Approach Summary (Iterative):
1. Initialize three pointers:
   - `prev = NULL`
   - `curr = head`
   - `next = NULL`
2. Traverse the list.
3. Reverse the link direction.
4. Move pointers forward.
5. Return `prev` as new head.

### ⏱ Time & Space Complexity:
- **Time:** O(n)
- **Space:** O(1)
