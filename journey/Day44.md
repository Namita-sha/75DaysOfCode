### 🔸 Problem Solved  
**2149. Rearrange Array Elements by Sign**

---

### 🔸 Problem Summary  
Given an array with an equal number of **positive and negative integers**, rearrange it such that:
- Every consecutive pair has **opposite signs**
- The array **starts with a positive number**
- The **relative order** of positive numbers and negative numbers is preserved

---

### 🔸 Approach Used
- Stored positive and negative numbers separately (or used index-based placement)
- Placed positives at even indices and negatives at odd indices
- Ensured order preservation while constructing the result array

---

### 🔸 Key Concepts Practiced
- Array traversal
- Stable ordering
- Index-based placement
- Handling constraints without in-place requirement

---

### 🔸 Time & Space Complexity
- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)`

---

### 🔸 Pattern Used
- Two-pointer / index placement pattern
- Array reordering with constraints
