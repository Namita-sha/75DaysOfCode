## 🧠 DSA Progress

### 🔸 Problem Solved  
**13. Roman to Integer**

#### 🔹 Approach Overview
- Used a map to store Roman numeral values
- Traversed the string from left to right
- If the current value was smaller than the next value, subtracted it
- Otherwise, added it to the total

#### 🔹 Key Learnings
- Handling subtraction cases (IV, IX, XL, XC, CD, CM)
- String traversal with conditional logic
- Clean mapping-based solution

## 🌐 System Design — Fundamentals Overview

### 🔸 Topics Covered

#### 1️⃣ Client–Server Architecture
- Client sends requests
- Server processes and responds
- Foundation of all web applications

#### 2️⃣ IP Address
- Unique identifier for servers on the internet
- Problem of memorability and changeability

#### 3️⃣ DNS (Domain Name System)
- Maps domain names to IP addresses
- Resolves human-friendly URLs to machine-readable addresses

#### 4️⃣ Proxy & Reverse Proxy
- Proxy: hides client identity
- Reverse Proxy: hides server identity
- Used for security, load balancing, and traffic control

#### 5️⃣ Latency
- Time taken for request–response round trip
- Reduced using geographically distributed servers

#### 6️⃣ HTTP / HTTPS
- Request–response communication protocol
- HTTPS adds SSL/TLS encryption for security

#### 7️⃣ APIs
- Interface between client and server
- Enables structured communication using JSON/XML

#### 8️⃣ REST API (Overview)
- Stateless
- Resource-based
- Uses HTTP methods (GET, POST, PUT, DELETE)
- Widely used API architecture
