### 🔸 Problem Summary  
Given a **sorted array of positive integers** and an integer `k`, find the **kth missing positive number** that does not appear in the array.

---

### 🔸 Approach Used
- Observed how many numbers are missing before each index
- Used logic based on the difference between the value and its expected position
- Solved efficiently by traversing the array and adjusting `k`


---

- **Space Complexity:** `O(1)`
