### 🔸 Problem Solved  
**1021. Remove Outermost Parentheses**

---

### 🔸 Problem Summary  
Given a valid parentheses string, decompose it into **primitive valid parentheses strings** and remove the **outermost parentheses** from each primitive part. Return the resulting string.

---

### 🔸 Approach Used — Counter / Stack Depth Logic
- Maintained a counter to track current parentheses depth
- Ignored the first `(` and last `)` of every primitive string
- Added characters to result only when depth > 1

---

### 🔸 Key Concepts Practiced
- Parentheses depth tracking
- String construction
- Primitive decomposition logic
- Stack-like behavior using a counter

---

### 🔸 Time & Space Complexity
- **Time Complexity:** `O(n)`
- **Space Complexity:** `O(n)` (for result string)
