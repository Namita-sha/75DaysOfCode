### 🧠 Approach Summary:

2. Traverse the string from left to right.
3. If the current value is less than the next value → subtract it.
4. Otherwise → add it.
5. Accumulate the final result.

### ⚡ Key Observations:
- Roman numerals follow additive + subtractive rules.
- Edge cases matter (like IV, IX, CM).
- Clean logic > complex code.
